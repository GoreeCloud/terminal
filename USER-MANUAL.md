# User Manual

## Development Foundation

Run:

```bash
./build/src/goreecloud-terminal
```

The application starts the shell specified by `$SHELL`, falling back to `/bin/sh`.

The context ribbon currently shows local/elevated privilege state, user@host, working directory, and session state.

Clipboard shortcuts:

- Copy: `Ctrl+Shift+C`
- Paste: `Ctrl+Shift+V`

Current limitations include no tabs, panes, SSH, profiles, settings, search, persistence, container workflows, onboarding, or production-grade Glaze UI acceptance.
